# 🎨 Teoría de Colores Aplicada - YoMinero

## 📐 Regla 60-30-10 (Fundamento Científico)

La **regla 60-30-10** es el estándar de oro en diseño profesional:

- **60%** = Color DOMINANTE (fondos, superficies grandes, backgrounds)
- **30%** = Color SECUNDARIO (elementos medianos, cards, secciones)
- **10%** = Color ACENTO (botones, highlights, CTAs, badges)

---

## 🥇 Identidad de Marca: ORO + NARANJA

### Color Base Principal: ORO METALIZADO
**Hex:** `#D4AF37` (Oro clásico metalizado)

**Por qué ORO:**
- ✅ **Psicología**: Riqueza, prestigio, confianza, éxito, logros
- ✅ **Industria Minera**: Relación directa con extracción de oro
- ✅ **Luxury Branding**: Posicionamiento premium
- ✅ **Cultura**: Valor universal (riqueza en Occidente, realeza en Asia)

### Color Energético: NARANJA VIBRANTE
**Hex:** `#FF6B35` (Naranja del botón radial - TU FAVORITO)

**Por qué NARANJA:**
- ✅ **Psicología**: Energía, optimismo, innovación, confianza, creatividad
- ✅ **Industria**: Seguridad (cascos, chalecos), equipo pesado
- ✅ **Branding**: Moderno, accesible, dinámico (vs. oro tradicional)
- ✅ **Visibility**: Alto contraste, llama la atención

## 🎨 PALETA YOMINERO - Aplicación 60-30-10

### ⚪ 60% - DOMINANTE (Fondos y Neutrales)

**Propósito**: Crear espacio, no cansar la vista, permitir que los acentos brillen

```
Cream Cálido:     #F8F5EF  ← Principal (backgrounds)
Beige Suave:      #F2EEE7  ← Alternativo
Blanco Cálido:    #FFFBF5  ← Cards y superficies
```

**Uso**: 
- Fondos de página (60% del diseño)
- Cards principales
- Áreas grandes de contenido

---

**Propósito**: Identidad de marca, elementos medianos, secciones importantes

```
ORO PRINCIPAL:
  Oro Metalizado:   #D4AF37  ← Base (30% del diseño)
  Oro Brillante:    #F4E4C1  ← Highlights
  Oro Oscuro:       #B8941E  ← Sombras
  Oro Puro 24K:     #FFD700  ← Premiums
```

**Uso**:
- Headers de secciones
- Badges premium
- Cards de productos destacados
- Elementos de navegación
- Marcos y bordes importantes

## 🎯 Colores Complementarios (Balance Visual)

### Color Complementario del ORO: AZUL

**Por qué AZUL:**
- ✅ **Teoría**: El azul es el complementario directo del oro en el círculo cromático
- ✅ **Contraste máximo**: Crea equilibrio visual perfecto
- ✅ **Psicología**: Confianza, profesionalismo, estabilidad (perfecto para empresa)
- ✅ **No compite**: No choca con oro ni naranja

```
AZUL CORPORATIVO (para Empresa):
  Azul Turquesa:    #45B7D1  ← Empresa (ya lo usas)
  Azul Profundo:    #3B82F6  ← Corporativo
  Navy Blue:        #1A2C50  ← Premium dark
```

**Uso**: 
- Módulo de Empresa (10-15% del diseño total)
- Contraste con oro en gráficos
- Elementos de confianza (login, payments)

## 🌈 Armonías de Color Aplicadas

### 1. Armonía ANÁLOGA (Cálida)
**Colores vecinos en círculo cromático**

```
Oro ← Naranja → Rojo
#D4AF37  #FF6B35  #DC2626
```

**Uso**: Gradientes naturales, transiciones suaves

### 2. Armonía COMPLEMENTARIA (Contraste)
**Colores opuestos en círculo cromático**

```
Oro/Naranja ↔ Azul
#D4AF37 / #FF6B35 ↔ #45B7D1
```

**Uso**: Elementos que necesitan destacar (CTA azul sobre fondo oro)

### 3. Armonía TRÍADA (Balanceada)
**3 colores equidistantes en círculo**

```
Oro → Verde → Púrpura
#D4AF37  #00D084  #9333EA
```

**Uso**: Categorías, tipos de posts, badges diferentes

## 🎯 Aplicación Práctica

### ✅ HACER:
1. **Fondos**: 60% cream/beige cálido
2. **Elementos principales**: 30% oro (headers, cards premium)
3. **Botones de acción**: 10% naranja vibrante
4. **Usar gradientes multicapa** (5-7 capas) para oro y naranja
5. **Complementar con azul** para balance en empresa

### ❌ NO HACER:
1. ❌ No usar naranja al 50% (sobrecarga visual)
2. ❌ No usar oro plano (debe tener gradiente)
3. ❌ No mezclar oro con verde o púrpura intenso sin neutrales
4. ❌ No ignorar la regla 60-30-10
