## ✅ CÓMO USAR

### ✅ HACER:
```dart
// Fondo (60%)
Container(color: AppColorsUnified.background)

// Header oro (30%)
Container(
  decoration: BoxDecoration(
    gradient: AppColorsUnified.goldGradient,  // 5 capas!
  ),
)

// Botón naranja (10%)
ElevatedButton(
  style: ElevatedButton.styleFrom(
    backgroundColor: AppColorsUnified.orange,
  ),
)

// Con context extension
Text('Premium', style: TextStyle(color: context.colorGold))
Container(decoration: BoxDecoration(gradient: context.gradientOrange))
```

### ❌ NO HACER:
```dart
❌ Container(color: Color(0xFFD4AF37))  // Hardcoded!
❌ Usar naranja al 50% (sobrecarga visual)
❌ Usar oro plano sin gradiente (se ve flat)
❌ Mezclar oro con verde/púrpura sin neutrales
```
